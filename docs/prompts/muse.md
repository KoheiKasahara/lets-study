# Muse 用プロンプト

Muse（や、AGENTS.md を自動では読まない AI）に作業を頼むときに、そのまま貼って使うひな形です。
ルールの本体は [AGENTS.md](../../AGENTS.md) にあり、ここでは「まず読ませる」「範囲を絞る」「確認させる」だけを行います。

## 最初に貼るもの（会話の先頭で1回）

```text
あなたは「レッツスタディ」（保育園児向け学習クイズ。React + TypeScript + Vite の静的サイト）の
リポジトリで作業します。

作業を始める前に、必ず次の順で読んでください。
1. AGENTS.md（構成・書き方の決まり・やってはいけないこと）
2. README.md
3. これから触るファイルと、その隣のテスト

進め方の約束：
- 頼んだことだけをやる。ついでのリファクタ、依存の追加、ファイルの移動はしない。
  必要だと思ったら、手を動かす前に理由を添えて提案する。
- 書く前に、変更するファイルの一覧と方針を3〜5行で示す。
- 画面を変えたら、スマホ縦（375×667）・スマホ横（667×375）・PC（1440×900）で
  横スクロールが出ないこと、ボタンがスクロールなしで押せることを確認する。
- 最後に `npm run check` を実行し、出力の末尾をそのまま貼る。
  失敗したらテストやルールを消さずに原因を直す。直せなければ、何が失敗しているかを正直に報告する。
- main には push しない。作業ブランチを切ってプルリクエストにする。

終わったら次の形で報告してください。
- 変えたファイルと、それぞれ何をしたか（1行ずつ）
- 確認したこと（npm run check の結果、見た画面サイズ）
- やらなかったこと・気になったこと（あれば）
```

## 作業ごとに貼るもの

### カテゴリを足す

```text
クイズのカテゴリを1つ足してください。

- カテゴリ：<なまえ（ひらがな）>　id：<英小文字>　アイコン：<絵文字>
- 対象：保育園児。問題文も選択肢も ひらがな中心、文節のあいだに半角スペース。
- 問題数：12問。選択肢は4つで重複なし。正解の位置は偏らせない。
- 絵文字で見せられる問題は visual に絵文字を入れる。
- explanation には、こどもが「へえ」と思える一言を入れる。

やり方は AGENTS.md の「カテゴリを足す」に従い、src/data/categories/animals.ts を手本にしてください。
画面とクイズ基盤のコードは変えないでください。
```

### 画面の見た目を直す

```text
<画面名> の <どこ> を <どうしたい> ように直してください。

- 困っていること：<いま何が起きているか。端末と向きも>
- こうなってほしい：<直ったあとの状態>
- 変えてよい範囲：src/screens/<画面名>.tsx と同名の .css のみ
  （共通の色・サイズが足りなければ src/styles/tokens.css に変数を足す提案をしてください）

色・文字サイズ・余白は tokens.css の変数を使い、ブレークポイントは AGENTS.md にある3つだけを使ってください。
```

### バグを直す

```text
次のバグを直してください。

- 起きること：<実際の動き>
- 期待する動き：<本来の動き>
- 再現手順：<1. … 2. … 3. …>
- 端末・向き：<例：iPhone 縦>

先にバグを再現するテストを足し、それが失敗するのを確かめてから直してください。
原因が分かったら、直す前に「原因」と「直し方」を2〜3行で教えてください。
```

## うまくいかないとき

| 起きること                       | 追加で伝えること                                                                    |
| -------------------------------- | ----------------------------------------------------------------------------------- |
| 関係ないファイルまで書き換える   | 「変えてよいのは <ファイル名> だけ。ほかを変えたくなったら先に聞いて」              |
| 新しいライブラリを入れたがる     | 「依存は増やさない。いまある React と CSS だけで」                                  |
| 幅や高さを px で決め打ちする     | 「AGENTS.md の CSS の決まりを読み直して。固定幅は禁止、tokens.css の変数を使う」    |
| 「できました」と言うが壊れている | 「npm run check の出力の末尾を貼って。貼れないなら実行していないと見なす」          |
| 漢字まじりの文言を書く           | 「こどもが読む文字は ひらがな中心・文節スペース区切り。AGENTS.md の『文言』を見て」 |
